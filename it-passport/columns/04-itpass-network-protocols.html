インターネットや社内LANの通信を支える「ネットワーク技術」。英字3〜4文字のプロトコル名（TCP, UDP, DNS, DHCP, HTTP等）やIPアドレスの仕組みは、文系・初学者が苦手意識を持ちやすい分野です。しかし、「手紙の郵送システム」に例えて階層構造を理解すれば、驚くほど簡単に整理できます。本記事では、ITパスポートで狙われる頻出ポイントを分かりやすく図解します。
目次

1. 通信の共通ルール「プロトコル」と階層化のメリット

メーカーやOS（Windows, Mac, iPhone, Android）が異なるコンピューター同士が通信するためには、世界共通の取り決め（ルール）が必要です。この通信規約を「プロトコル（Protocol）」と呼びます。

プロトコルは1つの巨大なルールにするのではなく、「アプリケーション」「通信の信頼性」「宛先のルーティング」「物理的な電気信号」のように役割ごとに階層化（レイヤー化）されています。これにより、ある層の技術（例：有線LANからWi-Fiへの変更）が変わっても、Webブラウザのプログラム自体を作り直す必要がなくなります。

2. TCP/IP 4階層モデルと主要プロトコル一覧

インターネットで事実上の世界標準となっているのが「TCP/IPモデル」です。

階層（レイヤー） 主な役割 代表的なプロトコルと機能
第4層：アプリケーション層 ユーザーが使うアプリ（Web、メール等）ごとのデータ形式を規定 ・HTTP / HTTPS：Webページの送受信（Sは暗号化）
・SMTP：メールの「送信」
・POP3 / IMAP：メールの「受信」（IMAPはサーバー上で管理）
・DNS：ドメイン名（URL）とIPアドレスを相互変換
・DHCP：IPアドレスを端末に自動割り当て
第3層：トランスポート層 通信の「信頼性」や「伝送効率」をコントロールする ・TCP：3ウェイハンドシェイクで接続確認。確実性を重視。
・UDP：確認応答なしで連続送信。動画配信や音声通話向け。
第2層：インターネット層 世界中のネットワーク間でデータを目的地まで届ける（ルーティング） ・IP：IPアドレスを用いてパケットを中継・配送
・代表機器：ルーター
第1層：ネットワークインターフェース層 同一LAN内の通信（物理的なケーブルや電波）を制御する ・Ethernet（有線LAN）、Wi-Fi（無線LAN）
・機器固有の識別番号：MACアドレス（48ビット）
・代表機器：スイッチングハブ

3. TCPとUDPの決定的な違い（試験頻出対比）

TCP vs UDP の違い

  • TCP（Transmission Control Protocol）：「確実性・信頼性」重視。データを送信する前に相手と接続を確立（3ウェイハンドシェイク）し、パケットの抜け落ちがあれば再送する。Web閲覧（HTTP）やメール送受信（SMTP）に使われる。
  • UDP（User Datagram Protocol）：「速度・リアルタイム性」重視。事前の確認を行わず一方的にデータを送り続ける。少々のデータ欠損があっても遅延を嫌う、YouTubeの動画ストリーミング、Zoom等のオンライン通話、DNSの問い合わせに使われる。

4. IPアドレスの基本：IPv4 と IPv6 の違い

IPアドレスは、インターネット上のコンピューターに割り振られる「住所」です。

規格 ビット数・表記方法 アドレス総数と特徴
IPv4 32ビット
8ビットずつ10進数でドット区切り
（例：192.168.1.1）		 約43億個（2の32乗）。インターネットの急速な普及によりアドレスが枯渇。
IPv6 128ビット
16ビットずつ16進数でコロン区切り
（例：2001:0db8::1）		 約340澗個（実質無限）。セキュリティ機能（IPsec）が標準搭載。

サブネットマスクの役割（ネットワーク部とホスト部）

IPアドレスは「どのネットワークに属しているか（ネットワーク部）」と「その中のどの端末か（ホスト部）」の2つの部分から構成されます。その境界線を決めるのが「サブネットマスク」です。

例：IPアドレスが「192.168.1.100」で、サブネットマスクが「255.255.255.0」の場合、先頭3つ（192.168.1）が同一ネットワーク内の住所を表し、最後の「100」が端末番号を表します。

5. 本試験の頻出チェック問題

過去問演習：プロトコルの機能判定

【問題】インターネットに接続されたPCが、Webサイトを閲覧する際に「www.example.com」のようなドメイン名から、対応するIPアドレスを自動的に問い合わせて取得するプロトコルはどれか？

【正解】DNS（Domain Name System）

【解説】人間が理解しやすいドメイン名（URL）と、PC同士が通信に使う数字のIPアドレスを変換（名前解決）する仕組みがDNSです。DHCP（IPアドレスの自動配布）との混同に注意しましょう。
